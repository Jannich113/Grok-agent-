# Skills in this kit

Open the matching `SKILL.md` **before** building. Routing lives in root `AGENTS.md`.

- **`auth`** — Auth via the Grok broker (Google, X) or local email/password — no other methods supported
- **`building-games`** — Browser games: loop, 3D orientation, camera, perf, assets, genres
- **`controls`** — Control signs, inverted A/D fix, vehicle/flight maps, mandatory self-test
- **`design-ui`** — Polished, non-generic UI: tokens, layout, type, color, motion, anti-slop
- **`game-animation-frames`** — Video-first animation frames that actually cycle
- **`game-asset-core`** — Core rules + engine-ready defaults for game assets
- **`game-character-consistency`** — Same character, every image
- **`game-tilesets`** — Seamless tiles and transition sets that actually tile
- **`game-ui-icons`** — Game UI kits and icon sets
- **`generate2dmap`** — 2D game maps: layered art, props, collision metadata
- **`generate2dsprite`** — 2D sprite sheets: imagine_text_to_image + magenta chroma postprocess
- **`imagine`** — Prompting and workflow guidance for Imagine image/video tools
- **`multiplayer-p2p`** — WebRTC P2P mesh, signaled at /api/rtc
- **`neon`** — Neon Postgres (with a local PGLite fallback) for this template
- **`og`** — Brand assets: og.jpg card, X feed banner, SVG favicon, PWA icons — always a non-blocking `task` subagent
- **`threejs`** — Three.js + TSL API (npm + official docs, no CDN r128)
- **`video2dsprite`** — Video→dense sprites (imagine_image_to_video + chroma postprocess)
- **`xai-api`** — xAI API via the injected XAI_API_KEY: chat, Imagine (image/video), voice
